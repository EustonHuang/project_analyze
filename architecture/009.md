# architecture/009: agent-trace-view 流程图可用性重构

## 背景

流程图虽然能渲染，但用户反馈交互体验差，主要有四方面问题：

1. **节点/标签太小**：流程图覆盖层里节点挤在一起，label 看不清。
2. **没有缩放/平移**：用户无法放大看细节、拖动画布。
3. **流程图独占一页**：当前是全屏覆盖层，遮住了 Source Inspector 和 File Viewer，点击节点后看不到具体信息，也无法与左右栏目联动。
4. **三栏宽度固定**：用户无法拖动中间两条分隔线调整左/中/右面板宽度。

## 方案

### 1. 把流程图从全屏覆盖层移入中间面板

中间 `sourcePanel` 改为**标签页**切换：
- 「来源详情」页：保持现有的 Source Inspector。
- 「流程图」页：内嵌 `#cy` 容器。

顶部 header 的「流程图」按钮改为切换中间面板的当前标签。去掉 `#graphOverlay` 覆盖层。

点击流程图中的节点时：
- 同步选中左侧树中的对应节点；
- 在右侧 File Viewer 中打开来源文件；
- 自动切换到「来源详情」标签显示该节点详情。

### 2. 节点与标签放大

Cytoscape 节点样式调整：
- `width: 180`, `height: 70`
- `font-size: 13`
- `text-max-width: 170`
- 边和箭头同步加粗，确保可读。

### 3. 缩放/平移与工具栏

Cytoscape 启用：
- `userZoomingEnabled: true`
- `userPanningEnabled: true`
- `wheelSensitivity: 0.3`

在流程图页内增加浮动工具栏：
- 放大（`+`）
- 缩小（`-`）
- 适应窗口（`⟲ 适应`）

### 4. 可拖动分隔线

在 `#treePanel` 与 `#sourcePanel` 之间、`#sourcePanel` 与 `#filePanel` 之间各加一条 `.resizer`。

行为：
- 鼠标按下 → 开始拖拽。
- 鼠标移动 → 调整相邻面板的 `flex-basis`。
- 鼠标释放 → 记录最终宽度到 `localStorage`，刷新后保持。
- 设置 `min-width`（180px / 280px）防止面板被拖没。

## 验收标准

1. 顶部「流程图」按钮能在「来源详情」与「流程图」之间切换，不再弹出全屏覆盖层。
2. 流程图页内节点标签清晰可读，可用鼠标滚轮缩放、拖拽画布。
3. 点击流程图节点，左侧树高亮、右侧文件查看器定位、中间切换到来源详情显示节点信息。
4. 三个主面板之间可以拖动分隔线调整宽度，刷新后保持上次宽度。
