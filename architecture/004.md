# architecture/004: agent-trace-view 可用性与来源可追溯性改进方案

## 目标

让 `agent-trace` / `agent-trace-view` 达到"人能看、来源能查"：

1. 每个工作流节点的来源必须能追到具体文件行号或系统提示原文，拒绝 "inferred" 这类空来源。
2. Viewer 布局必须可折叠、来源可一眼看到，不再把中间大片区域留给失败的图视图。

## 当前问题

### 来源不可追溯

`agent_traces/agent_system_workflow.json` 中多处使用 `type: inferred` / `path: skill execution model`，无文件、无行号、无原文引用。例如：

- `n14: skill 是否需要进一步调用工具？` → `inferred`
- `n21: 进入通用问题求解流程` → `inferred`
- `n25: 是否需要继续调用工具？` → `inferred`

这些节点在 viewer 中无法验证，违反 architecture/003 中"每个节点必须带 source"的本意。

### UI 不可读

- 左侧树按递归 children 渲染，缩进过深，一长串 `▸ step:` 难以扫描。
- 中间图视图区域空白（Cytoscape.js 未正确渲染或不可见），成为视觉垃圾。
- 来源详情挤在右侧窄栏，用户需要点节点才能看到，且无法收起左侧树。

## 方案

### 1. 来源必须具体

workflow 模型中 `node.source` 只接受两类：

- `type: "file"`：必须是仓库内的真实文件，字段 `path` + `line_start` + `line_end` + `quote`。例如：
  - `.codebuddy/skills/agent-trace/SKILL.md` 第 1-33 行
  - `.codebuddy/skills/agent-trace/scripts/validate.py` 第 11-65 行
- `type: "system_prompt"`：注入的系统提示/工具描述，字段 `section` + `quote`。因系统提示没有行号，用 section 名 + 原文段落代替。

禁止 `type: inferred`。若某一步确实无法定位到文件或系统提示原文，则：

- 要么从 workflow 中删除该节点；
- 要么移入独立的 `assumptions[]` 数组，显式标记为"设计假设"，不作为事实节点渲染。

`scripts/validate.py` 必须拒绝任何不含 `line_start`（file 类型）或 `section`（system_prompt 类型）的 source。

### 2. UI 重排

Viewer 改为三栏，全部可折叠：

- 左侧：Phase Navigator
  - 按 phase 分组，phase 标题可折叠。
  - 每个 phase 内节点平铺展示，不再递归缩进。
  - 节点行显示形状图标 + kind + label，决策节点高亮。
  - 提供"只看决策"开关，仅列出所有 decision 节点。
- 中间：Source Inspector
  - 默认占据主区域，显示当前选中节点的完整来源。
  - 对 `file` 类型：展示 path + line range + quote，并提供"在 IDE 打开"链接格式。
  - 对 `system_prompt` 类型：展示 section + quote。
  - 未选中节点时展示 workflow 概览（phase 数、节点数、条件数）。
- 右侧：Graph View
  - 默认收起；点击"图"按钮展开。
  - 保留 Cytoscape 渲染，但不再作为默认主视图；若 Cytoscape 加载失败，显示文字版拓扑列表。

### 3. 验收标准

- `agent_system_workflow.json` 中不存在 `type: inferred`。
- 每个 skill 相关节点必须指向某个 `.codebuddy/skills/<name>/SKILL.md` 的具体行号。
- Viewer 左侧可折叠，中间区域在选中节点时直接显示来源引用，不依赖右侧窄栏。
- `validate.py` 对非法 source 报错并退出非零。

## 交付物

1. 重写 `agent_traces/agent_system_workflow.json`：替换所有 `inferred` 为具体 file/system_prompt 来源，必要时删除或移入 `assumptions[]`。
2. 更新 `agent-trace/references/trace_template.md`：明确 source 的两类要求。
3. 更新 `agent-trace/scripts/validate.py`：校验 `line_start` / `line_end` / `section`。
4. 重写 `agent-trace-view/web/app.js`、`index.html`、`styles.css`：三栏可折叠布局 + Source Inspector 居中 + Phase Navigator 平铺。
5. 更新 `agent-trace-view/SKILL.md` 与 server 透传逻辑。
