# architecture/010: agent-trace-view 流程图改为左侧面板 + 层级按需展开

## 背景

上一版把流程图做成了中间面板的标签页，但用户实际想要的是：

1. **流程图应该放在左侧面板**，与「步骤列表」切换显示，而不是和中间的来源详情抢位置。
2. **流程图默认只展示顶层步骤**，点击某个步骤才展开/收缩它的子步骤。
3. 展开/收缩逻辑是递归的：点击步骤 1 展开 1.1/1.2/1.3；再点击 1.1 展开 1.1.1/1.1.2；再点一次则收起。

## 方案

### 1. 左侧面板改为标签页

`#treePanel` 顶部增加两个标签：
- **步骤**：现有的阶段/节点树形列表。
- **流程图**：用 Cytoscape 渲染的可交互流程图。

移除中间面板的「来源详情/流程图」标签，中间面板恢复为纯粹的来源详情，右侧保持文件查看器。

### 2. 流程图改为层级展开图

使用 trace 里每个节点的 `children` 以及决策节点的 `yes_branch` / `no_branch` 构建父子关系。

- 初始只显示顶层根节点（`roots`）。
- 维护 `expandedNodes: Set<string>`，记录哪些节点处于展开状态。
- 节点可见条件：`is root` OR `parent expanded && parent visible`（递归到根）。
- 边可见条件：源节点和目标节点都可见。
- 点击节点：
  - 若该节点有子节点且未展开 → 加入 `expandedNodes`，显示子节点。
  - 若已展开 → 从 `expandedNodes` 移除，并递归移除所有后代，隐藏整个子树。
  - 同时执行 `select(n, true)`，更新中间来源详情与右侧文件。

### 3. 可展开/折叠的视觉提示

- 叶子节点：正常节点样式。
- 有子节点且已展开：正常样式 + `expanded` 类。
- 有子节点且未展开：`collapsed` 类，使用虚线边框（`border-style: dashed`），提示可点击展开。

### 4. 布局与缩放

- 仍使用 `breadthfirst` 自顶向下布局。
- 每次展开/收缩后重新运行 `layout`，`animate: false` 保持快速响应。
- 保留右上角工具栏：放大、缩小、适应窗口。
- 保留滚轮缩放与画布拖拽。

## 验收标准

1. 左侧面板有「步骤」「流程图」两个标签，可切换。
2. 流程图默认只显示顶层节点，子节点隐藏。
3. 点击有子节点的节点，展开其所有后代；再次点击收起。
4. 收起状态的节点有明显的视觉提示（虚线边框）。
5. 点击任意节点，中间面板显示该节点来源详情，右侧文件查看器定位到对应代码。
6. 三栏之间的可拖动分隔线继续保留。
