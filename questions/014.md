# Q14 — 调用 agent-trace-view 后 server 一直前台运行、卡住命令行，为什么？

## 现象
按 skill 说明运行 `python3 server/server.py ...` 后，前后端 server 一直占用命令行不退出，
agent 卡在该命令上无法继续，必须手动杀掉进程才能发下一个 prompt。

## 根因
`server/server.py` 末尾：

```python
HTTPServer((args.host, args.port), Handler).serve_forever()
```

`serve_forever()` 是阻塞调用。当作为一条普通 CLI 命令在前台执行时，进程永远占住
shell / agent 的命令通道，直到被外部终止。skill 的启动说明没有提供后台化或退出机制，
导致命令行被挂死、用户只能强杀。

## 修复方向
- 启动命令改为后台 / 分离运行（`nohup python3 ... &` 或 `setsid`），释放命令行；
- 或在 server 内加看门狗：空闲超时（如 N 分钟无请求）自动 `shutdown()` 自退；
- 或提供显式 stop 指令 + PID 文件，便于干净退出；
- skill 说明应明确「后台启动 + 如何停止」，避免用户只能强杀进程。
